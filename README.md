

# DDPM 扩散模型项目

## 项目简介

本项目实现了一个基于去噪扩散概率模型（Denoising Diffusion Probabilistic Model, DDPM）的图像生成系统。DDPM是近年来最受关注的生成模型之一，通过模拟数据逐步扩散和去噪的过程，能够生成高质量的图像样本。

项目采用模块化设计，核心组件包括UNet神经网络架构、扩散过程调度器、训练 pipeline 以及可视化工具，支持在 MNIST 和 CelebA 等数据集上进行训练和采样。

## 核心特性

**扩散模型核心**：实现了完整的DDPM算法，包括前向扩散过程和反向去噪采样过程。前向过程逐步向数据添加高斯噪声，反向过程通过神经网络学习去噪操作。

**UNet架构**：采用带时间条件嵌入的U型网络作为去噪模型，包含残差块、注意力模块和上采样下采样模块。残差块用于特征提取，注意力模块捕获长距离依赖，U型结构保证多尺度信息融合。

**时间条件编码**：使用正弦位置嵌入（Sinusoidal Time Embedding）将扩散步骤编码为高维向量，通过MLP注入到网络各层，使模型能够根据不同去噪阶段自适应调整。

**多数据集支持**：内置MNIST手写数字数据集和CelebA人脸数据集的处理流程，通过配置文件可灵活切换。MNIST适用于快速验证和小规模实验，CelebA用于生成更复杂的自然图像。

**训练工具**：提供完整的训练框架，包括学习率调度、模型检查点保存与加载、早停机制、样本网格生成等功能。支持从中断点恢复训练。

## 环境要求

项目基于 Python 3.8+ 开发，核心依赖包括 PyTorch 2.0 及以上版本、TorchVision 用于数据处理、PyYAML 用于配置文件解析。训练CelebA数据集建议使用 NVIDIA GPU，显存不少于8GB可获得较好效果。

## 安装步骤

克隆仓库到本地后，创建并激活虚拟环境，建议使用 conda 或 venv 管理依赖。通过 pip 安装项目依赖，若使用 GPU 训练，需确保 CUDA 环境配置正确。

```bash
git clone <仓库地址>
cd 26summer
pip install -r requirements.txt
```

## 快速开始

项目提供预置的配置文件用于不同数据集的训练。使用 main.py 作为入口程序，通过 `--config` 参数指定配置文件路径。

```bash
# 使用 MNIST 配置训练
python main.py --config configs/mnist.yml

# 使用 CelebA 配置训练
python main.py --config configs/celeba.yml
```

训练过程中会定期生成样本网格到指定目录，检查点文件保存在与运行名称对应的文件夹中。训练完成后，可使用 demo.py 中的函数进行采样和可视化。

## 配置文件说明

配置文件采用 YAML 格式，包含模型架构参数、训练超参数、数据集路径等设置。MNIST 配置适用于快速实验，默认使用较小批次和较短训练轮数。CelebA 配置针对高质量人脸生成优化，使用更大批次和更长时间的训练。

关键配置项包括：模型的基础通道数、扩散步骤数、学习率、批次大小、图像尺寸、数据集根目录路径等。修改这些参数可适应不同硬件条件和实验需求。

## 核心模块详解

**diffusion.py** 实现了DDPM的核心逻辑。forward_diffusion 方法接收原始图像和时间步，在指定时间步添加对应程度的高斯噪声。training_loss 方法计算去噪损失函数，使用均方误差衡量预测噪声与实际添加噪声的差异。sample 方法执行反向采样过程，从纯噪声开始逐步去噪生成新图像。

**model.py** 定义了完整的UNet去噪模型。SinusoidalTimeEmbedding 使用正弦和余弦函数生成时间步的嵌入向量，这种编码方式借鉴于Transformer架构。TimeMLP 将时间嵌入映射到适合网络操作的维度。ResidualBlock 结合时间条件信息和图像特征，残差连接帮助深层网络的训练。AttentionBlock 采用多头自注意力机制增强模型对图像细节的建模能力。DownSample 和 UpSample 实现特征图的压缩和还原，配合跳跃连接保留多尺度信息。

**train.py** 包含训练流程的完整实现。extract_celeb 和 preprocess_celeb 函数处理原始CelebA图像数据。load_mnist 函数加载并归一化MNIST数据集。save_sample_grid 将生成的样本拼接成网格图像便于直观比较。检查点相关函数支持训练中断后恢复，以及保存最优模型。

**demo.py** 提供便捷的可视化工具。to_image 和 show_image 用于将张量转换为可视化图像格式。capture_reverse 可视化反向去噪过程的中间结果，直观展示图像从噪声逐渐清晰的过程。demo_animate 生成去噪过程的动画演示。

## 模型检查点

训练过程中会在 checkpoins 目录下保存模型状态。建议使用最新检查点（latest）继续中断的训练，使用最佳检查点（best）进行最终采样。检查点包含模型参数、优化器状态、学习率调度器状态、当前轮数和损失值等信息。

## 算法原理

扩散模型的核心思想是学习数据分布的逆向转换。前向扩散过程在 T 个时间步内逐步向数据添加噪声，每一步的噪声水平由预定义的调度器控制。反向去噪过程从纯噪声分布开始，神经网络预测每一步应当去除的噪声，逐步还原出数据分布的样本。

训练目标是使神经网络预测的噪声与实际添加的噪声尽可能接近，使用均方损失函数。通过变分下界推导，这一目标等价于最大化证据下界（ELBO）。采样时使用均值为预测值加当前状态、方差由调度器决定的公式迭代更新。
